# US Stock Market Time Series Analysis

## Objective
This project focuses on analyzing US stock market data using Time Series Analysis techniques.

The main goal is to identify:
- Trends
- Seasonality patterns
- Market behavior over time

Forecasting using Random Forest was added as an optional predictive analysis section.

---

## Dataset
The dataset contains historical stock market data including:
- Date
- Open Price
- Close Price
- High Price
- Low Price
- Trading Volume

---

## Tasks Performed
- Data Cleaning
- Trend Analysis
- Moving Average Analysis
- Seasonality Detection
- Data Visualization
- Forecasting using Random Forest
- Streamlit Deployment

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

---

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Trend Analysis
4. Seasonality Detection
5. Forecasting
6. Visualization
7. Deployment

---

## Key Insights
- Stock prices fluctuate significantly over time.
- Moving averages help identify long-term trends.
- Monthly average analysis reveals seasonal patterns.
- Trading volume often changes during volatile periods.
- Random Forest predictions follow actual trends reasonably well.
